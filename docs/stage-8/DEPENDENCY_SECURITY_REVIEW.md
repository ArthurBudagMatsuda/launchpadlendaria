O bundle público é estático, não um servidor Node. O Worker importa validação/imagem/jose, não Jayson/Anchor. A entrada browser de web3.js importa `jayson/lib/client/browser`, que usa JSON/generateRequest, não o parser stream-json. Essa é uma revisão de exposição da implementação atual, não uma certificação independente de toda a árvore.

O patch em `patches/bigint-buffer@1.1.5.patch` mantém a API JS existente e remove o carregador nativo da entrada distribuída/source. `check-beta-security.mjs` verifica a instalação real, simula disponibilidade de bindings para exigir **zero tentativas de carregamento**, e faz **36 checagens de conversão** em buffers vazios e 64/128/256/2048 bits. Os SDKs, serializer e fluxos dos dois validadores passaram. O gate roda antes de build Beta; a auditoria ainda reporta a versão upstream sem correção oficial.

Não atualizar SDKs indiscriminadamente, habilitar rebuild nativo, remover patch ou forçar stream-json 3.x em dependentes sem validar APIs. O risco Mainnet continua aberto junto com a revisão independente.
